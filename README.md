# BTC ATM Short Straddle

An automated BTC options short-straddle prototype
using NautilusTrader and Bybit Testnet.

## Technology

- Python
- NautilusTrader
- Bybit Testnet
- Streamlit
- Plotly
- SQLite
- Pytest

## Safety

- Testnet only
- DRY_RUN by default
- No mainnet execution

## Run the application

Start the trading application:

    python main.py

Start the dashboard in another terminal:

    streamlit run dashboard/app.py
